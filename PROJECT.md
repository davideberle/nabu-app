# Nabu — Companion App

Personal household companion app for the Eberle family. Deployed on Vercel at
https://app.davideberle.com.

## Stack

- **Framework**: Next.js 16 (App Router, Server Components)
- **Auth**: NextAuth v5 (Google OAuth, single-user allow-list)
- **Database**: Turso (libSQL) via `@libsql/client` — shared by todos, My Recipes, meal plans, and cook history
- **Styling**: Tailwind CSS v4
- **Hosting**: Vercel (auto-deploy from `main`)

## Environment Variables (Vercel)

- `TURSO_DATABASE_URL` — Turso database URL
- `TURSO_AUTH_TOKEN` — Turso auth token
- `AUTH_SECRET` — NextAuth secret
- `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET` — Google OAuth credentials
- `IPAD_TRACKER_ONLY_EMAILS` — optional comma-separated Google accounts restricted to family iPad surfaces; defaults to `assistant@davideberle.com`
- `OPENAI_API_KEY` — optional; enables real OpenAI Realtime voice-coach sessions for family routine proof checks. If unset, the route returns demo mode.
- `TRUSTED_RUNTIME_TOKEN` — bearer token for local non-browser runtimes (Telegram live-cooking helper) to perform Cooking Session writes. **Fail-closed**: missing, blank, or under 20 characters means no bearer credential authorizes anything. Generate with `openssl rand -base64 48`.
- `FAMILY_BRIDGE_TOKEN_SECRET` — server-only. Signs the short-lived, child-scoped token `/api/family/assistant/session` mints for `/family/assistant`. Must be ≥32 characters and byte-identical to the secret the Mac mini bridge resolves from its Keychain. **This is not the OpenClaw Gateway bearer**, which grants operator scope over the whole household and never leaves the Mac mini. Never `NEXT_PUBLIC_`.
- `FAMILY_ASSISTANT_BRIDGE_URL` — server-only; `https://dae-macmini.tail4f656e.ts.net:8787`. The tailnet origin the browser posts child turns to. Must be `https:`: a plaintext non-loopback value is refused at mint time, so a mistyped origin yields a 503 rather than a child bearer token in clear on the tailnet. Served to the browser in the mint response rather than inlined at build time, so it is not a `NEXT_PUBLIC_` constant either.

Both Family Assistant variables are Production-only and server-side. If either is missing the mint route fails closed with a 503 and `/family/assistant` shows a recovery message; it never falls back to an unauthenticated or plaintext path.
